#
# ## 1. 核心节奏与结构（固定 90 秒 · 10 分镜）
# - **画幅**：1920×1080（16:9），Canvas 逻辑分辨率 `1920x1080`，CSS 自适应窗口居中显示。
# - **总时长**：严格 `90.0` 秒，拆分为 10 个独立场景函数 `renderScene1` ~ `renderScene10`。
# - **第 17.0 秒锚词重拍爆发（核心记忆点）**：
#   - `scene-01`（0–6s）：痛点开场，抛出现实矛盾。
#   - `scene-02`（6–12s）：动态拉扯/现象推演。
#   - `scene-03`（12–18.5s）：前 5 秒压缩蓄力，在**总时间轴 `t = 17.0s`** 准时触发微震动 + 冲击波 + 巨型发光核心锚词（2~5个字，例如「依恋错位」「多巴胺陷阱」等）。
#   - `scene-04` ~ `scene-08`（18.5–68.5s）：用物理小球、波形图、能量条、闭环图拆解正反机制、核心反转与消耗代价。
#   - `scene-09`（68.5–81s）：给出可视化的破局方法/解法。
#   - `scene-10`（81–90s）：金句升华 + 互动提问收尾。
# - **底部 Tagline**：每个分镜开始后 **`0.9s`（必须在 `0.8~2.5s` 之间）** 准时弹出，禁止拖到分镜末尾才出现。
#
# ## 2. 视觉与交互规范
# - **禁止**：禁止使用 CDN 外部脚本；禁止任何 `Math.random()`（粒子必须确定性预生成）；禁止鼠标悬停放大图片/元素。
# - **配色**：根据主题情绪定制高级深色背景与高对比度双色对撞（如情感类用午夜紫黑 `#0F0C1D` + 珊瑚红 `#FF5E7E` + 冰雾蓝 `#4DA8FF` + 高光金 `#FFD166`；商业/科技类可换用深海蓝/琥珀金等），避免千篇一律的黑客绿。
# - **声音**：内置 Web Audio API 合成节拍与 17.0s 重低音爆发音效。
#
# ## 3. 导出 MP4 必须暴露的全局接口（缺一不可）
# 为了让 `render_mp4.py` 能逐帧精确导出 16:9 MP4，HTML 的 `<script>` 内必须暴露：
# - `window.__duration = 90.0;`
# - `window.__seekTo = (t) => { ... };`（调用后必须同步立即重绘对应时刻 `t` 的 Canvas 画面）
# - 控制栏容器 ID 为 `#controls`，开场遮罩 ID 为 `#startOverlay`，渲染脚本启动时会自动隐藏它们。

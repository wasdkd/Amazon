清洗前的准备

数据清洗（Data Cleaning）是数据科学中最关键的环节。在开始之前，确保安装并导入以下核心库：

import pandas as pd    # 核心数据处理
import numpy as np     # 数值计算与 NaN 处理
import re              # 正则表达式
import datetime        # 时间日期处理

# 载入数据
df = pd.read_csv('data.csv') # 或 pd.read_excel('data.xlsx')
01

数据探索与质量检查

在动手之前，你必须通过以下函数全方位了解数据的“健康状况”：

df.head(10)            # 查看前10行，初步感知数据
df.info()               # 核心：查看每列数据类型、非空值数量、内存占用
df.describe()           # 查看数值列统计信息（均值、标准差、四分位数）
df.isnull().sum()       # 统计每一列缺失值的绝对数量
df.isnull().mean()      # 统计缺失值百分比（专家推荐：直观评估列可用性）
df.nunique()            # 查看每列唯一值数量，识别分类变量或无效常数列
df.sample(5)            # 随机抽取5行（专家推荐：避免前几行数据过好而产生的偏见）
02

缺失值处理 (Missing Data)

专家提示： 缺失值不一定都要删。如果缺失比例低于5%，可以考虑填充；如果超过50%，考虑直接删掉该列。

1. 彻底删除

df.dropna(inplace=True)               # 删除任何包含 NaN 的行
df.dropna(axis=1)                    # 删除包含 NaN 的列
df.dropna(subset=['Age', 'Salary'])   # 仅当 Age 或 Salary 缺失时删除行
df.dropna(thresh=3)                  # 保留至少有3个非空值的行

2. 智能填充

# 填充固定值
df['Score'] = df['Score'].fillna(0)

# 统计学填充（均值/中位数）
df['Age'] = df['Age'].fillna(df['Age'].median())

# 业务逻辑填充：按分组填充（专家推荐）
# 例如：按“职位”填充“薪资”的缺失值
df['Salary'] = df.groupby('Job_Title')['Salary'].transform(lambda x: x.fillna(x.mean()))

# 邻近填充（常用于时间序列）
df['Price'].fillna(method='ffill') # 前向填充：用上一行值填充
df['Price'].fillna(method='bfill') # 后向填充：用下一行值填充
03

重复值处理

# 1. 查找重复
df.duplicated().sum()             # 统计完全重复的行数

# 2. 删除重复
df.drop_duplicates(inplace=True)  # 保留第一次出现的行，删除其余

# 3. 指定列去重（最常用）
# 场景：同一个用户 ID 有多条记录，只保留最新的一条
df.drop_duplicates(subset=['User_ID'], keep='last', inplace=True)
04

字符串清洗与提取

Pandas 的 .str 访问器提供了强大的向量化字符串处理能力。

# 1. 基础修整
df['Name'] = df['Name'].str.strip()         # 去首尾空格
df['City'] = df['City'].str.lower()         # 转小写
df['City'] = df['City'].str.title()         # 首字母大写

# 2. 替换与清理
# 将金额中的 $ 和 , 删掉，并转为浮点数
df['Price'] = df['Price'].str.replace('$', '').str.replace(',', '').astype(float)

# 3. 信息提取 (正则表达式)
# 从地址中提取 5 位邮编
df['Zip_Code'] = df['Address'].str.extract(r'(\d{5})')

# 4. 包含与判断
# 筛选所有 Email 中包含 "gmail" 的行
gmail_users = df[df['Email'].str.contains('gmail', na=False)]
05

数据类型转换

专家提示： 转换前请先使用 errors='coerce'。它会将无法转换的值设为 NaN，而不是报错中断程序。 
# 1. 转换为数值
df['Sales'] = pd.to_numeric(df['Sales'], errors='coerce')

# 2. 转换为日期 (极其重要)
df['Order_Date'] = pd.to_datetime(df['Order_Date'], errors='coerce')

# 3. 强制转换类型
df['ID'] = df['ID'].astype(str)
df['Age'] = df['Age'].astype(int, errors='ignore')
06

列名重命名与规范化

# 1. 指定重命名
df.rename(columns={'Old_Name': 'New_Name', 'Date Of Birth': 'DOB'}, inplace=True)

# 2. 批量清洗列名（专家推荐）
# 规范：全小写，空格变下划线，去首尾空格
df.columns = [c.lower().strip().replace(' ', '_') for c in df.columns]
07

异常值检测与盖帽

IQR 四分位距法

Q1 = df['Salary'].quantile(0.25)
Q3 = df['Salary'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# 策略：直接过滤
df_clean = df[(df['Salary'] >= lower_bound) & (df['Salary'] <= upper_bound)]

# 策略：盖帽法 (Clipping) - 将超出范围的值设为边界值
df['Salary'] = df['Salary'].clip(lower=lower_bound, upper=upper_bound)
08

分组聚合 (GroupBy)

分组不仅是为了看报告，更是为了生成特征数据。

# 1. 基础聚合
# 按城市计算薪资均值和人数
city_stats = df.groupby('City').agg({'Salary': 'mean', 'User_ID': 'count'})

# 2. 进阶：多指标并行
agg_res = df.groupby('Dept').agg({
    'Salary': ['sum', 'mean', 'max'],
    'Bonus': 'std'
})

# 3. 专家级：transform
# 计算“个人薪资”占“部门总薪资”的比例
df['Dept_Total'] = df.groupby('Dept')['Salary'].transform('sum')
df['Salary_Ratio'] = df['Salary'] / df['Dept_Total']

Pivot Table (行转列)

# 用于制作汇总报表
df.pivot_table(
    index='Date',
    columns='Region',
    values='Sales',
    aggfunc='sum'

# 用于将宽表变为长表

df.melt(
    id_vars=['ID'],

多表合并与关联

# 1. 纵向合并（增加行，多月数据拼接）
df_full = pd.concat([df_jan, df_feb], axis=0)

# 2. 横向关联（类似于 SQL Join）
# how 可以是 'left', 'right', 'inner', 'outer'
merged_df = pd.merge(orders, users, on='User_ID', how='left')

时间序列处理

# 设置日期为索引
df['Date'] = pd.to_datetime(df['Date'])
df.set_index('Date', inplace=True)

# 提取特征
df['Year'] = df.index.year
df['Month'] = df.index.month
df['Day_of_Week'] = df.index.dayofweek

# 重采样 (Resampling)
# 将每日数据按月汇总均值
monthly_avg = df['Sales'].resample('M').mean()

# 滑动窗口 (Rolling)
# 计算 7 天移动平均线
df['MA7'] = df['Sales'].rolling(window=7).mean()

性能优化：数据专家的进阶技巧

1. 禁用循环

绝对不要在 Pandas 里用 for index, row in df.iterrows()。它的速度比向量化运算慢 1000 倍以上。

2. Category 类型

对于“城市”、“等级”等重复率高的字符串列，转换为 category。内存占用可减少 80%。

df['City'] = df['City'].astype('category')

3. Parquet 存储

CSV 读取慢且不包含类型信息。处理百万级数据时，请使用 df.to_parquet()。

数据清洗标准工作流 (Standard SOP)

1 载入数据并执行 info()、sample() 查看质量。
2 规范列名（去空格、统一下划线、小写）。
3 处理字符串（strip 空格、正则替换、统一格式）。
4 类型转换（特别是日期和数值）。
5 缺失值治理（按需填充或删除）。
6 重复值去重（重点关注业务主键 ID）。
7 异常值检测与盖帽。
8 执行 df.info() 最终验证清洗结果。

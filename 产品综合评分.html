评分: 4.2-4.8星产品质量好 | 评分数: 100-2000个数据可靠 | 留评率: 0.1%-1%为正常范围

优先选择: 评分80+ | 月销量1000-3000 | 价格$20-35 | 卖家≤3 | BSR排名稳定 | 毛利率>35% | 上架6-18个月的产品

各维度详细计算过程

1. 销售表现维度 (权重30%)
  • 月销量评分:
  • 归一化值 = 5,040 / 3,750 = 1.344
  • 限制最大值为2，所以为1.344
  • 得分 = 1.344 × 0.4 = 0.538
  • 月销售额评分:
  • 归一化值 = 194,443 / 125,000 = 1.555
  • 限制最大值为2，所以为1.555
  • 得分 = 1.555 × 0.4 = 0.622
  • 销量增长率评分:
  • 归一化值 = 55 / 35 = 1.571
  • 限制最大值为2，所以为1.571
  • 得分 = 1.571 × 0.2 = 0.314
  • 销售表现总分:
  • 0.538 + 0.622 + 0.314 = 1.474
  • → 限制在1.000 (最大值)
  • 销售表现贡献:
  • 1.000 × 30% = 0.300
2. 利润潜力维度 (权重25%)
  • 价格区间评分:
  • $38.58 在 $30-50 范围内
  • 得分 = 0.7
  • 评分数/销售额比评分:
  • 比值 = 4,258 / (194,443 / 38.58) = 0.845
  • 在 0.5-2 之间
  • 得分 = 0.8
  • 毛利率评分:
  • 预估毛利率 64.3% ≥ 40%
  • 得分 = 0.9
  • 利润潜力总分:
  • (0.7 × 0.4) + (0.8 × 0.3) + (0.9 × 0.3) = 0.28 + 0.24 + 0.27 = 0.79
  • 利润潜力贡献:
  • 0.79 × 25% = 0.198
3. 竞争分析维度 (权重20%)
  • 卖家数量评分:
  • 2 个卖家 ≤ 3 个
  • 得分 = 0.9
  • 贡献 = 0.9 × 0.4 = 0.36
  • 大类BSR评分:
  • 归一化值 = 6,237 / 8,500 = 0.734
  • 反向处理值 = 1 - 0.734 = 0.266
  • 得分 = 0.266 × 0.3 = 0.080
  • 小类BSR评分:
  • 归一化值 = 52 / 150 = 0.347
  • 反向处理值 = 1 - 0.347 = 0.653
  • 得分 = 0.653 × 0.3 = 0.196
  • 竞争分析总分:
  • 0.36 + 0.080 + 0.196 = 0.636
  • 竞争分析贡献:
  • 0.636 × 20% = 0.127
4. 产品质量维度 (权重15%)
  • 评分评分:
  • 归一化值 = 4.7 / 5 = 0.94
  • 得分 = 0.94 × 0.5 = 0.47
  • 评分数评分:
  • 4,258 在 100-5000 范围内
  • 得分 = 0.8
  • 贡献 = 0.8 × 0.3 = 0.24
  • 留评率评分:
  • 2.14% 在 1%-3% 范围内
  • 得分 = 0.5
  • 贡献 = 0.5 × 0.2 = 0.1
  • 产品质量总分:
  • 0.47 + 0.24 + 0.1 = 0.81
  • 产品质量贡献:
  • 0.81 × 15% = 0.122
5. 增长潜力维度 (权重10%)
  • 上架时间评分:
  • 1,560 天不在 90-360 天范围内
  • 得分 = 0.4
  • 贡献 = 0.4 × 0.4 = 0.16
  • 月新增评价评分:
  • 归一化值 = 108 / 85 = 1.271
  • 限制最大值为2，所以为1.271
  • 得分 = 1.271 × 0.4 = 0.508
  • 营销标识加分:
  • 假设具有 Best Seller 标识
  • 加分 = 0.1
  • 增长潜力总分:
  • 0.16 + 0.508 + 0.1 = 0.768
  • 增长潜力贡献:
  • 0.768 × 10% = 0.077

最终综合评分计算

综合评分 = 销售表现贡献 + 利润潜力贡献 + 竞争分析贡献 + 产品质量贡献 + 增长潜力贡献

综合评分 = 0.300 + 0.198 + 0.127 + 0.122 + 0.077 = 0.824

转换为百分制: 0.824 × 100 = 82.4分

评分说明

  • 所有数值指标均使用75%分位数作为基准进行归一化处理，避免极值产品对评分的影响
  • 归一化值限制最大为2，防止极端值对评分体系的过度影响
  • BSR排名采用反向处理，数值越小得分越高
  • 各维度权重总和为100%，确保评分体系的平衡性
